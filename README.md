# MovieCity — Landing Page

Projeto feito com React + Vite e CSS puro.

## Como executar

1. Instale Node.js (versão compatível com o Vite).
2. Abra o terminal nesta pasta.
3. Execute:

```bash
npm install
npm run dev
```

4. Abra o endereço mostrado no terminal (normalmente http://localhost:5173).

## Imagens

Os arquivos de pôster ficam em `src/assets/`. O `afterlife.jpg` enviado foi incluído no projeto. Os demais arquivos são placeholders para que o projeto abra mesmo antes de você colocar suas imagens reais. Substitua-os mantendo os mesmos nomes.

## Verificar o projeto

```bash
npm run build
```
